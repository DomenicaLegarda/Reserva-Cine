# Sistema de Reserva de Asiento - Sala de Cine


- **Semana:** 12
  

- **Estudiante:** Legarda Mendoza Domenica Stefany

- ## 🎯 Objetivo del Programa
Gestionar la reserva de asientos en una sala de cine de **3 filas por 4 columnas**. El programa permite al usuario indicar la fila y columna del asiento deseado, marcarlo como reservado y mostrar el estado completo de la sala en formato de tabla. Se aplica el uso de **matrices (listas anidadas)**, acceso a elementos por índices y **recorrido mediante bucles anidados**.
